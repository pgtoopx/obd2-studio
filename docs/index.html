Bluetooth Low Energy (BLE 4.0+) Navegador Compatible

Conexión directa sin cables. Óptimo en Android (Chrome) y laptops con Bluetooth integrado. Compatible con vLinker MC+, Veepeak BLE+, Kingbolen y clones ELM327 BLE.

Web Serial (Cables USB & COM) Navegador Compatible

Para cables OBD2 USB (FTDI, CH340, Prolific, CP2102) o adaptadores Bluetooth clásico emparejados a un puerto COM serie en Windows o Linux.

Si tu adaptador no responde tras abrir el puerto, probá alternar entre 38400 y 115200.

Comprobando Bridge local...

Los navegadores web no pueden abrir sockets TCP directos a 192.168.0.10:35000 por políticas de seguridad del sandbox web. El script ligero obd2-wifi-bridge.py corre en tu equipo y puentea los datos en tiempo real.

⬇️ Descargar obd2-wifi-bridge.py
🪟 Windows (PowerShell 1-línea):
irm https://pgtoopx.github.io/obd2-studio/downloads/obd2-wifi-bridge.py -OutFile obd2-wifi-bridge.py; python obd2-wifi-bridge.py
🐧 Linux (Terminal 1-línea):
curl -fsSL https://pgtoopx.github.io/obd2-studio/downloads/obd2-wifi-bridge.py -o obd2-wifi-bridge.py && python3 obd2-wifi-bridge.py
